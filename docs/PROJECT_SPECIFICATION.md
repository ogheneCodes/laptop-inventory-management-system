# Laptop Inventory Management System (LIMS)

## Project Overview

This project is being developed as part of the Technology Solutions Engineer Program (TSEP) of Oghenemaga Signature.

The purpose of this application is to help laptop businesses manage inventory efficiently.

---

## Business Problem

Many laptop businesses manage inventory manually.

This leads to:

- Lost records
- Incorrect stock counts
- Difficulty tracking sales
- Difficulty calculating profit
- Poor customer service

---

## Proposed Solution

Develop a secure inventory management system that allows the business to:

- Add laptops
- Edit laptop information
- Delete laptops
- Search inventory
- Track sales
- Generate reports
